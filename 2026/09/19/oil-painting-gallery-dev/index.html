用 Python 和 Canvas 给博客搭一个油画画廊

发表于2026-09-19|更新于2026-10-20
|浏览量:

给 Hexo 博客做了个「AI 油画 + 裸眼 3D」画廊，前后端各一个模块，总共不到 500 行代码。这篇文章记录下实现思路。

整体架构

数据驱动，加画只需要在 source/_data/art.yml 里加一行。

模块一：Python 油画滤镜

核心思路很简单：

  1. 边缘检测 + 平滑混合：用 PIL 的 FIND_EDGES 拿到轮廓，SMOOTH_MORE 拿到色块，两者按边缘权重混合——边缘处保留锐度，平坦处做色块化。
  2. 色彩量化：quantize(colors=48) 把连续色阶压缩成 48 级，模拟油画的有限调色板。
  3. 画布纹理：用 np.sin 生成经纬交织的织物纹理，叠上高斯噪点——这一步让输出看起来像画布而不是数码照片。
  4. 暖色调增强：色彩 +15%、亮度 +3%、叠加一层暖黄（blend(warm, 0.06)），让整体偏暖。

整个脚本 70 行，pip install pillow numpy 就能跑，构建时 python tools/generate-oil.py 批量处理所有图片。

模块二：前端油画引擎

3D 视差

鼠标位置映射到 [-1, 1]，写入 CSS 变量。每张画卡片包一层 depth-layer，JS 根据 data-depth 属性计算位移：

深度值 1.0 的画卡片动 ±30px，文章封面 0.6 动 ±18px，页面 banner 0.4 动 ±12px——近处的动得多，远处的动得少，裸眼 3D 的关键就在这个差值。

油画 Canvas 混合

每张画卡片叠加一个 <canvas>，加载对应 oil 版图片，用 mix-blend-mode: soft-light 混合到原图上方。呼吸动画让 canvas 在 scale(0.985) ~ scale(1.015) 间缓慢脉动，模拟油画颜料在光线下的微妙反光。

滚动入场

IntersectionObserver 监听 .art-card，进入视口时加 .paint-reveal class，CSS 做 translateY(24px) → 0 + opacity 0 → 1，每张卡片按索引延迟 0.06s，瀑布式入场。

降级策略

  • 减弱动画模式：禁用所有过渡和 Canvas
  • 移动端：禁用视差，Canvas 降到 25% 透明度
  • 低端设备：纯静态展示，零性能开销

踩过的坑

  1. object-fit 困境：3:2 卡片里放全景画（如《睡莲·1917》宽高比 2.5:1），cover 裁掉两边，contain 缩小留黑边。最终方案：JS 动态判断——宽画用 contain 居中，正常画用 cover 填满。

  2. pjax 存活：Butterfly 主题开了 pjax，页面跳转不走 DOMContentLoaded。所有 JS 都要监听 pjax:complete 重新初始化。

  3. 脚本缓存：scripts/*.js 是 Hexo 构建时执行的，改完必须 npm run clean && npm run build，否则产物是旧的。

总结

两个模块各司其职：Python 在构建时把照片变成油画，前端在运行时让画”活”起来。总共 ~500 行有效代码，零外部依赖（Python 端只用 PIL + numpy，前端纯原生 JS + CSS），对 Hexo 生态完全透明——加画只改 YAML，不碰代码。

源码在我的 GitHub 仓库。
